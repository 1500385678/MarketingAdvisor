## 1. 品牌

| 字段 | 内容 |
|---|---|
| 品牌 | 小米(Xiaomi,2010 年成立,2021 年宣布造车,2024 年 3 月首款车 SU7 上市) |
| 主推单品 | 小米 SU7(标准版 21.59 万 / Pro 版 24.59 万 / Max 版 29.99 万) |
| 营销类型 | 新品发布(科技/汽车品类) + 创始人 IP(雷军个人流量) + 预热长跑 + 生态绑定(人车家全生态) |
| 行业 | 新能源汽车 / 智能硬件 / 科技消费品 |
| 调性反差 | 互联网"性价比"基因 × 30 万级豪华轿跑 × 3 年造车 × 雷军"are you OK"个人 IP × 苹果/特斯拉对标 |

**为何选这个案例**:小米 SU7 是 2024 年中国新能源车市场最具话题性的"破圈发布"——3 年跨界造车、首款车直接对标 Model 3、订单破 10w 用时 24h(锁单 27 分钟破 5w)、女性车主占比近 50%、把"雷军个人 IP"做成了"小米汽车的标配发动机"。**新品类 + 高客单价 + 创始人 IP + 长周期预热,这套打法在国产新势力里具有标杆意义**,适合作为"科技 / 新品发布 / 高客单价"品类的范本。

## 2. 目标

| 维度 | 目标 | 量化指标 |
|---|---|---|
| 品牌势能 | 把小米从"手机/IoT 品牌"升级为"人车家全生态品牌" | SU7 发布后"小米汽车"百度指数峰值 ≥ 200w(3-28 发布会当晚) |
| 销售转化 | 首战即爆款,树立 30 万级纯电轿跑新标杆 | 上市 24h 订单 ≥ 10w · 锁单 27 分钟破 5w · 4 月单月交付 ≥ 1w 台 |
| 用户结构 | 撕掉"米粉 = 性价比男性"标签,拉新女性 + 高净值用户 | 女性车主占比 ≥ 40%(行业基线 20-25%) · 30 万+ 价位段订单占比 ≥ 60% |
| 渠道闭环 | 把"小米之家 + 京东/天猫 + 抖音直播"打成统一发售通路 | 上市首日全国 60+ 城小米之家同步试驾 · 抖音直播发布会 1.5 亿人次观看 |
| 心智锚点 | 让"小米 SU7"在 30 万级纯电轿跑里与 Model 3 / 极氪 001 / 智界 S7 形成"四强"心智 | 新车垂媒(汽车之家/懂车帝)关注度 TOP3 · 微博热搜累计 ≥ 50 条 |

**战略意图**:小米要"用一场发布会,把 3 年造车的赌注一次性押在用户认知里";**核心打法 = 创始人 IP 顶流 × 长周期技术预热 × 高调对标(保时捷/Tesla)× 人车家生态绑定 × 女性用户破圈**。

## 6. 复盘(做得对/做错/下次怎么做)

### ✅ 做对
- **雷军个人 IP 系统化**:把"小米 CEO"升级为"小米汽车首席产品经理+首席营销官",3 年个人微博 + 抖音内容矩阵沉淀,发布会一晚 1.5 亿人次观看,这是国产车圈从未有过的创始人流量
- **长周期技术预热 vs 短周期订单收割**:SU7 不是"发布即上市",而是"2021 官宣 → 2024 发布 → 持续预热",3 年悬念 + 1 年参数披露,用户认知成本被分摊到 36 个月
- **高调对标策略**:不回避"对标保时捷/Tesla",反而主动让雷军在发布会拿出对比图,这种"年轻态对标"反而拉高了用户期待,21.59-29.99 万价格带"年轻人第一台保时捷"心智锚点成型
- **女性用户破圈**:海湾蓝/橄榄绿配色 + 防晒天幕/化妆镜/补光特写 + 小红书 KOC 提前种草,让女性车主占比从行业 20% 拉到 40%+,撕掉"理工男"标签
- **人车家生态绑定**:HyperOS 跨端演示(手机控车/平板副驾屏/家居互联),把"汽车"从单点产品升级为"小米生态入口",提升用户换车决策的"换生态"权重

### ❌ 做错
- **产能爬坡缓慢**:4 月单月交付 7058 台(订单 10w+),锁单用户等待 8-12 周,部分用户转投极氪/智界
- **事故舆情**:3 月底 SU7 高速 NOA 事故 + 4 月海口试驾 ABS 故障,虽官方快速回应,但被竞品反复引用放大
- **价格预期管理不足**:发布前市场普遍预期 14.99-19.99 万,实际起售 21.59 万,导致部分老米粉"失望退订",舆论出现"小米不厚道"声音
- **智驾叙事模糊**:发布会后用户对"小米智驾 vs 华为 ADS vs 小鹏 XNGP"对比无清晰认知,雷军"2024 年底开通全国"的承诺被吐槽过度宣传
- **女性营销深度不够**:配色 + 化妆镜是表层,没有针对女性用户的"安全/副驾/亲子/接送"场景做深度内容,导致部分女性用户仍持观望

### 🔄 下次怎么做
- **产能前置 + 预售透明化**:发布前 6 个月公告"首批产能 5w 台,4 月起周交付 1.5k 台",用透明预期管理用户等待
- **智驾分阶段承诺 + 行业基准对标**:把"全国都能开"拆解为"高速 NOA → 城市 NOA → 端到端"3 阶段,每阶段配竞品对标数据,降低舆论风险
- **女性场景深度内容矩阵**:副驾美妆 / 接送小孩 / 闺蜜自驾 / 城市夜归 4 大场景,每个场景 30 条短视频 + 1 个真实用户故事
- **价格阶梯 + 选装包灵活化**:把 21.59 万作为"入门即满配"信号,Pro/Max 走"高净值用户"心智,选装包(音响/座椅/智驾)灵活拆分,降低决策门槛
- **创始人 IP 团队化**:雷军主推品牌战略 + 培养"产品经理天团"(赵长江/胡峥楠)做技术沟通,降低个人 IP 风险
