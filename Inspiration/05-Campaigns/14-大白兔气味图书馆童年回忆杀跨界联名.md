## 1. 品牌

| 字段 | 内容 |
|---|---|
| 品牌 1 | **大白兔奶糖**(上海冠生园,1943 年创立,2019 年 76 年历史的国民奶糖,2019 年品牌焕新关键节点) |
| 品牌 2 | **气味图书馆 Demeter**(2009 年进入中国,定位"场景化嗅觉品牌",以"还原生活场景气味"为产品哲学) |
| 合作类型 | 跨界联名(Cross-over Co-branding)· **老字号国货焕新 × 童年回忆杀 × 跨界联名子品类**(全新子品类) |
| 行业跨度 | 食品糖果(国民奶糖) × 美妆香水(场景化嗅觉 IP) |
| 调性反差 | 国民童年奶糖(均价 5-15 元/斤) × 都市生活方式香水(285 元/60ml) |

**为何选这两个 IP**:
- 大白兔 2019 年 76 岁,**在 Z 世代集体回忆杀 + 国潮回潮双重红利下寻找品牌焕新机会**
- 气味图书馆在中国一直在做"中国式场景"(豆浆/书墨/火锅/红枣),但**缺一个真正的国民级 IP 锚点**
- 双方共同把"童年回忆"转化为"日常可穿戴的嗅觉符号",从"吃"到"闻"的感官跨界

## 2. 目标

| 维度 | 目标 | 量化指标 |
|---|---|---|
| 拉新 | 把 Z 世代 + 都市白领从童年回忆拉到香水消费场景 | 大白兔香水联名款销售 ≥ 50 万瓶 |
| 焕新 | 撕大白兔"廉价糖纸 + 老一辈"标签,贴"国潮 + 怀旧"心智 | 微博 #大白兔香水# 阅读 ≥ 2 亿 |
| 销量 | 联名款香水 + 周边秒空 | 上线 1 小时售罄 ≥ 1 万件 |
| 心智 | 让大白兔从"5 毛奶糖"升级为"国潮生活方式 IP" | 联名后 6 月大白兔品牌搜索指数 ×3 |

**战略意图**:
- 大白兔要"借气味图书馆的香水场景,把'童年'从味觉拓展到嗅觉 + 生活方式"
- 气味图书馆要"借大白兔的国民级怀旧流量,完成中国市场的二次破圈"
- 双方共同把"国货老字号 + 新消费场景"的化学反应推到现象级

## 4. 创意(可执行层)

### 4.1 Slogan 层级
- **主 Slogan**:大白兔,快乐童年味儿
- **辅 Slogan**:"一喷回到 1990" · "闻到它,想起外婆的糖罐" · "童年的味道,现在闻得到"

### 4.2 KV 视觉(4 大场景主题)
- **PV1 经典蓝白**:大白兔经典蓝白包装 + 香水瓶身同框,回忆感
- **PV2 童年场景**:糖纸 + 课桌 + 老式搪瓷杯,场景化
- **PV3 国潮新意**:蓝白主色 + 国潮线条,焕新感
- **PV4 礼盒装**:联名礼盒(香水 + 奶糖 + 帆布袋),送礼向

### 4.3 联名周边(爆款核心)
- **联名香水 60ml**:售价 285 元(气味图书馆原版香水均价 145 元/25ml),大白兔奶糖味定制香调
- **联名礼盒**:香水 + 大白兔奶糖 1 袋 + 蓝白帆布袋,售价 605 元
- **联名香氛**:大白兔奶糖味车载香氛 / 房间香薰,99-149 元价格带
- **联名身体乳 + 护手霜**:大白兔奶糖味日化线,199-299 元价格带

### 4.4 落地页 3 屏
1. **首屏**:蓝白大字"童年味儿,闻得到" + 香水瓶身特写
2. **二屏**:4 大场景 + 礼盒拆解 + 用户晒单(微博/小红书)
3. **三屏**:购买按钮 + "童年只有一次,这次不靠吃" 紧迫感文案

### 4.5 媒介标题 30 变体(选 5)
- "闻到它的那一刻,我回到了 1998 年的外婆家"
- "95 后的第一瓶香水,居然是小时候偷吃的大白兔"
- "谁说童年回不去?这瓶香水把大白兔喷在身上了"
- "520 送礼指南:这瓶香水让她想起你们小时候的糖罐"
- "小红书博主测评:大白兔香水到底值不值得买?"

## 6. 复盘(做得对/做错/下次怎么做)

### ✅ 做对
- **老字号 + 新场景化学反应精准**:奶糖味 → 香水的"感官跨界"绝配,媒介自带"童年回忆杀"二创素材
- **价格策略敢于拉高**:60ml 香水卖 285 元(远超原版 145 元/25ml),证明"老字号 IP + 限定"能撑溢价
- **周边延展节奏稳**:香水 → 礼盒 → 车载香氛 → 身体乳,产品矩阵完整,长尾销售支撑充分
- **微博话题运营成功**:童年回忆 + 香水体验双向话题,#大白兔香水# 阅读 2.3 亿,自然热度持续 30 天

### ❌ 做错
- **首发供给不足**:1 小时售罄 1 万件 + 大量用户没抢到,二次补货间隔 7-10 天,黄牛囤货严重
- **气味还原度争议**:部分用户反映"闻起来不像大白兔奶糖"而像"奶糖包装纸味",IP 还原度与期待有 gap
- **海外市场覆盖薄弱**:港台 + 海外华人买不到,部分代购水涨船高

### 🔄 下次怎么做
- **首批发货量提升 3 倍**:从 1 万件 → 3 万件,分 3 批(5-23 / 5-30 / 6-6),挤压黄牛空间
- **气味测试更严**:小范围内测 200 + 用户,把"还原度"从 60% 提到 85%+
- **出海同步**:与港台 + 新马泰 + 北美华人经销商同步首发,把"国货老字号焕新"推到全球华人圈
