## 1. 品牌

| 字段 | 内容 |
|---|---|
| 品牌 | 蜜雪冰城(中国下沉市场最大连锁茶饮品牌,门店数破 3 万) |
| 营销类型 | 事件营销(Event Marketing) + IP 化(国民品牌人格化) |
| 行业 | 现制茶饮(下沉市场为主) |
| 调性 | 极致性价比(均价 4-6 元) × 国民级反差萌(主题曲洗脑 IP) |

**为何选这个案例**:蜜雪冰城主题曲"你爱我我爱你,蜜雪冰城甜蜜蜜"是 2021 年现象级事件营销,以一首 19 秒循环主题曲 + 雪王 IP 完成"下沉茶饮 → 国民 IP"的品牌跃迁,**用最低成本实现了品牌势能的最大化**,适合作为"小预算 + 大声量"事件营销范本。

## 2. 目标

| 维度 | 目标 | 量化指标 |
|---|---|---|
| 拉新 | 把一二线城市的年轻人拉进蜜雪冰城门店 | 主题曲全网播放 ≥ 100 亿次 |
| 势能 | 撕掉"下沉土味"标签,升级为"国民 IP" | 雪王登上热搜 ≥ 20 次 |
| 销量 | 借主题曲流量拉升门店杯量 | 主题曲爆火后单店日销 +30% |
| 心智 | 把"雪王"塑造成类似"熊本熊"的国民 IP | 周边/联名/二创全网开花 |

**战略意图**:蜜雪冰城要"用一首主题曲,把全国人民都变成门店的免费 KOL";**核心打法 = 极简重复 × 主动让用户二创 × IP 化雪王人格**。

## 3. 策略(5 段式)

| 段 | 输出 |
|---|---|
| 目标人群 | 18-30 岁全网用户(下沉 + 都市年轻人叠加),核心是"爱二创 + 爱玩梗"的短视频用户 |
| 核心卖点 | **"19 秒循环洗脑,谁听谁上头"** —— 用极简旋律 + 高频重复制造传播钩子,让门店主题曲成为"出场自带 BGM" |
| 渠道组合 | 主投:B 站主题曲二创 + 抖音短视频模仿 + 门店实拍打卡;辅投:微博热搜 + 知乎"为什么这么洗脑"科普;测试:雪王 IP 联名(啤酒/咖啡/文具) |
| 内容矩阵 | Slogan"你爱我我爱你,蜜雪冰城甜蜜蜜"(19 字 × 5 段循环);KV 雪王雪人形象 × 高饱和红白撞色;落地页"门店主题曲同款杯套 / 雪王表情包 / 雪王周边"三件套;媒介标题 30 变体(鬼畜/教学/多语言/翻唱/打卡) |
| KPI | 主题曲 B 站播放 2000w+ / 抖音相关视频 50w+ / 微博热搜 20+ / 雪王二创周边 100+ / 主题曲爆火后单店日销 +30% |

## 4. 创意(可执行层)

### 4.1 Slogan 层级
- **主 Slogan**:你爱我我爱你,蜜雪冰城甜蜜蜜(口语化、押韵、19 字)
- **辅 Slogan**:雪王,每天来一杯;4 元的快乐,谁喝谁知道

### 4.2 KV 视觉
- **主视觉**:雪王(白色雪人 + 皇冠 + 权杖)形象 + 高饱和红白撞色 + 蜜雪冰城 logo
- **辅视觉**:门店门头巨型雪王玩偶(每个门店 1 只),形成"线下地标 + 线上 IP"闭环

### 4.3 落地页 3 屏(主题曲 H5)
1. **首屏**:循环播放主题曲 + "点击加入合唱"按钮,引导用户录音
2. **二屏**:用户录音上传 → 一键生成"你的雪王主题曲"短视频
3. **三屏**:分享到抖音/微博/朋友圈 + 门店定位 → 引导到店

### 4.4 媒介标题 30 变体(选 5)
- "蜜雪冰城主题曲听 10 遍,真的会上头"
- "老板让我翻译蜜雪冰城主题曲,我翻完笑死"
- "雪王求婚现场实录,这谁顶得住"
- "在蜜雪冰城门店唱主题曲,店员给我多放了 2 块糖"
- "我用 6 国语言唱了蜜雪冰城主题曲,你 pick 哪个"

## 5. 渠道与节奏

| 阶段 | 时间 | 动作 | 目的 |
|---|---|---|---|
| 预埋 | T-30 ~ T-1 | 主题曲上线 B 站 + 门店播放(每日 100+ 次) | 习惯性洗脑 |
| 引爆 | T 日 | B 站 UP 主翻唱 + 抖音 KOL 模仿 + 微博热搜"蜜雪冰城主题曲" | 集中爆破 |
| 二创 | T+1 ~ T+14 | 用户鬼畜/翻唱/多语言版本/雪王二创周边 | 持续扩散 |
| IP 化 | T+15 ~ T+90 | 雪王联名(啤酒/咖啡/盲盒/文具) | IP 沉淀 |
| 复盘 | T+90 ~ T+120 | 行业复盘稿 + "国民 IP 化"方法论沉淀 | 学术化 |

## 6. 复盘(做得对/做错/下次怎么做)

### ✅ 做对
- **极简重复**:19 字 × 5 段循环,把"旋律钩子"做到了极限
- **主动让用户二创**:开放主题曲版权 + 提供雪王 IP 素材,让二创规模指数级增长
- **线下线上闭环**:每个门店都成"主题曲 + 雪王玩偶"的打卡点,UGC 持续供给
- **IP 化人格**:雪王 = 蜜雪冰城,后续联名/周边/广告全部以雪王为主角,品牌资产沉淀

### ❌ 做错
- **门店卫生争议**:主题曲爆火后门店客流暴增,部分门店出现卫生问题,被网友曝光
- **海外主题曲授权争议**:部分翻唱/多语言版本未与原作者沟通,引发版权问题
- **过度依赖单一 IP**:雪王太成功,后续茶饮创新(如幸运咖)很难复制

### 🔄 下次怎么做
- **门店产能预案**:主题曲爆款后单店客流 +30-50%,需提前 2 周培训 + 备货
- **版权前置**:主题曲/雪王 IP 申请商标 + 著作权登记,开放二创但保留商业授权
- **多 IP 矩阵**:不止雪王,需要培养"雪妹/雪爸/雪弟"等次级 IP,分散单 IP 风险

## 7. 数据参考(实际结果)
