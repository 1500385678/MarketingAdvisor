## 6. 复盘

### 6.1 做对的事

1. **国家叙事 × 民族情绪 × 自主可控"三位一体"**:精准踩中"美方制裁 4 年低谷 → Mate 60 Pro 重返 → Mate 70 全链路自主可控"完整国家叙事时间线,激发国民情绪与民族自豪,微博话题 #华为Mate70# 阅读量 50 亿+,全民参与"中国科技突破"讨论
2. **HarmonyOS NEXT 纯血鸿蒙"破壁之战"**:作为中国首个全自研移动 OS + 世界第三大移动 OS(iOS / Android / HarmonyOS NEXT),完成"操作系统自主可控"最后一块拼图,余承东宣布"2025 年全部新机和 Pad 全部搭载 HarmonyOS NEXT",长线战略意义远超单次营销
3. **全球首款卫星寻呼"黑科技锚点"**:全球首发卫星寻呼技术(偏远地区 + 海上 + 灾害场景通信),为 Mate 70 系列建立"黑科技锚点",与 iPhone 16 + 三星 Galaxy S24 形成差异化,激发科技极客 + 商务人士 + 国民情绪消费者三大圈层
4. **预订 + 开售"加单 1700 万"供应链奇迹**:11-18 预订 5 分钟 27 万 → 11-19 早 8 时 200 万 → 11-26 18 时 334 万(新华社)→ 12-05 供应链加单 30% 至 1700 万台,创造 2024 年中国手机市场"加单奇迹",华为供应链 + 渠道 + 制造能力得到验证
5. **价格带全覆盖 + RS 非凡大师版"高端旗舰对标"**:5499-11999 元覆盖中端旗舰到顶级旗舰全价格带,RS 非凡大师版对标苹果 Pro Max + 三星 Galaxy Ultra,完成"国民品牌 + 高端旗舰"双重占位
6. **余承东"强得飞起"个人 IP 放大**:余承东作为华为终端 BG 董事长,亲任主推官贯穿全传播周期,微博 + 发布会 + 直播带货 + 央视新闻,个人 IP 与品牌 IP 高度统一,放大传播效率

### 6.2 做错的事

1. **HarmonyOS NEXT 兼容性挑战**:作为中国首个全自研移动 OS,部分安卓 App 兼容性 + 微信 + 支付宝 + 银行 App 迁移成本是潜在用户(尤其苹果老用户)最大顾虑,需要持续 OTA + 兼容性优化 + 数据迁移工具升级
2. **卫星寻呼实际使用场景有限**:虽然全球首款黑科技,但实际使用场景偏远地区 + 海上 + 灾害场景,对一二线城市用户的实际价值有限,可能被部分 KOL 质疑"噱头"
3. **产能爬坡 + 加单风险**:从 11-26 预订 334 万到 12-05 加单 1700 万,产能爬坡 + 供应链压力巨大,12 月初部分规格溢价 300-2000 元可能影响消费者情绪
4. **Mate 60 Pro 老用户升级周期**:2023-08 发布的 Mate 60 Pro 用户距今仅 15 个月,升级 Mate 70 系列意愿有限,需要更强升级权益 + 鸿蒙 OS 体验差异 + 卫星寻呼新增量

### 6.3 下次怎么做

1. **HarmonyOS NEXT 兼容性长线运营**:持续 OTA + 微信 + 支付宝 + 银行 App 适配 + 数据迁移工具升级 + 苹果切换指南,作为 2025 年长线运营核心
2. **卫星寻呼使用场景扩展**:从偏远地区 + 海上 + 灾害场景扩展到城市应急 + 户外探险 + 商务出差 + 国际旅行,扩大使用场景
3. **Mate 60 Pro 老用户升级权益**:为 Mate 60 Pro 老用户提供以旧换新 + HarmonyOS NEXT 升级礼包 + 卫星寻呼免费体验
4. **RS 非凡大师版独立营销**:作为对标苹果 Pro Max + 三星 Galaxy Ultra 的顶级旗舰,需要独立营销 + 高净值商务定位 + 身份认同强化
5. **产能 + 供应链长线投资**:加单 1700 万只是开始,2025 年 H2 + 2026 年 H1 持续投资产能 + 国产供应链,避免断货 + 溢价
