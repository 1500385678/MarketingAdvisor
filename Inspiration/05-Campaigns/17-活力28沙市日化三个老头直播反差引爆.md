# 案例 #17 · 活力 28 沙市日化 · 2022 三个老头直播间反差引爆营销(主体反差引爆)

> Phase 0 #5-16 历史优秀 Campaign 模板 #17

> 用途:喂给 5 段式策略生成器(目标人群—核心卖点—渠道组合—内容矩阵—KPI),作为**"老字号国货焕新 × 主体反差事件引爆 × 中价格带"**的第 1 个范本(与 #14 大白兔"老字号国货焕新 × 高价跨界 IP 焕新"、#15 蜂花"老字号国货焕新 × 低价良心反向种草"、#16 白象"老字号国货焕新 × 身份反差事件引爆"形成"老字号国货焕新四雄")

## 1. 品牌

| 字段 | 内容 |
|---|---|
| 品牌 1 | **活力 28**(沙市日化,湖北荆州,1982 年创立,2022 视角 40 年历史,国民老牌日化第二大企业,1990s 央视黄金时段"活力 28 沙市日化"广告家喻户晓) |
| 合作类型 | **无显式联名 / 主体反差引爆** · **老字号国货焕新 × 主体反差事件引爆 × 中价格带子品类**(全新子品类 #4,与 #14 高价跨界 IP 焕新、#15 低价良心反向种草、#16 低价身份反差引爆对照) |
| 行业跨度 | 日化 / 洗衣液 / 洗衣粉(国民基础消费品) |
| 调性反差 | **大陆老牌日化(19.9-39.9 元/件) × 外资日化(蓝月亮/立白/汰渍/奥妙 30-80 元/件) × 1996 年合资后被雪藏 26 年后回归** |

**为何选活力 28 作为范本**:

- 活力 28 1982 年创立,**40 年坚持"沙市日化"国民品牌身份**(在 1990s 巅峰期与活力 28、浪奇、纳爱斯、白猫并称"中国日化五朵金花")
- 1996 年与德国 TUD(后并入汉高)合资,**品牌被外资雪藏 26 年**(1996 → 2022 期间国内几乎不见活力 28 产品)
- 2022-09 三个平均 70 岁的老头(原沙市日化退休职工)在抖音直播间带货,**因"不会说普通话 + 不会操作直播 + 直接读产品说明书"反差感拉满**
- 网友"心疼式下单" —— 直播间从 0 涨到 100 万+ 粉丝,单场 GMV 破千万,"活力 28 三个老头"成 2022 网络热梗
- **活力 28 vs 大白兔 vs 蜂花 vs 白象:老字号国货焕新四条截然不同的路径**
  - 大白兔(食品糖果):**主动跨界 IP 焕新**(找气味图书馆合作 285 元香水,高价格带)
  - 蜂花(个护洗护):**被动口碑反向种草**(被消费者发现 9.9 良心价,低价格带)
  - 白象(食品方便面):**身份反差事件引爆**(产品配料雪碧梗 + 1/3 残疾员工,低价格带)
  - **活力 28(日化洗衣):****主体反差事件引爆**(3 个 70 岁老头直播,中价格带)

## 2. 目标

| 维度 | 目标 | 量化指标 |
|---|---|---|
| 翻红 | 把"被外资雪藏 26 年的国民老牌日化"拉回 Z 世代 + 国货消费者视野 | 抖音 #活力28# 累计 20 亿+ 播放(2022-2023 累计) |
| 焕新 | 撕"被外资买断/老气/怀旧"标签,贴"国民老牌 + 老头真心 + 良心国货"心智 | 抖音 #活力28三个老头# 10 亿+ 播放 |
| 销量 | 抖音直播间 GMV 翻 10 倍,从月销百万到月销千万 | 抖音直播间单场 GMV 千万+(2022-12 多次破千万) |
| 心智 | 让"活力 28 = 沙市日化 40 年老牌 + 三个老头的良心"成消费者心智默认 | 全网"活力 28"相关话题 60+ 持续长尾 |

**战略意图**:

- 活力 28 本身**不主动营销**(没有大规模广告投放,3 个老头就是原沙市日化退休职工),但消费者被它的"主体反差"打动
- 关键洞察:不是"我去请 KOL 直播",而是"用户(三个退休老头)自发直播 + 不会操作直播的反差感被消费者发现 + 引发'心疼式下单'反向引爆"
- 与"低价身份反差引爆"形成完整四路径:主动跨界 vs 被动反向种草 vs 身份反差 vs **主体反差**
- 重要补充:**主体反差是"由用户自创内容触发"**,与"事件引爆"和"身份反差引爆"有交集但不完全等同
  - #11 鸿星尔克是"被事件激发(捐款 5000 万)"
  - #16 白象是"被身份反差打动(1/3 残疾员工 + 配料雪碧梗 + 大陆国货)"
  - **#17 活力 28 是"被主体反差感动(3 个 70 岁老头直播不会说普通话,直接读产品说明书)"**

## 6. 复盘(做得对/做错/下次怎么做)

### ✅ 做对

- **"三个退休老头就是主播"反而成最大营销**:活力 28 没花大钱请 KOL,被消费者"自发主体反差发现"反向引爆,2 年累计 20 亿+ 抖音播放
- **"不会说普通话 + 不会操作直播" = 天然话题**:两个反差元素都是"国民老牌良心"心智锚点,被网友自发二创切片 + 媒体跟进 + 平台放大
- **"主体反差引爆"路径稳定**:每次翻红都是"用户自创内容(三个老头直播)→ 网友自发二创切片 → 媒体跟进 → 平台放大 → 销量兑现",2 年持续验证
- **长尾极强**:从 2022-09 到 2023-12 持续翻红,2 年 60+ 话题,无衰减,符合"国民老牌良心"心智的复利效应
- **"被雪藏 26 年"叙事加成**:1996 → 2022 这段时间几乎是国货空窗期,被网友重新发现后"失而复得"情绪拉满,反向引爆强于普通老国货

### ❌ 做错 / 风险

- **"被外资雪藏"叙事反噬**:2023 年有部分舆论指出活力 28 早期授权外资有"卖国"嫌疑,部分消费者动摇,品牌叙事需重新定位
- **三个老头后续争议**:三个退休老头后续被曝部分直播内容"有剧本",反差感真实性受质疑
- **产品创新弱**:主要还是 1990s 经典款,新 SKU 研发慢,产品力跟不上翻红速度
- **价格带中端尴尬**:19.9-39.9 元不上不下,高端化(对比蓝月亮 49.9-80 元)推进弱,下沉市场被蜂花(9.9 元)和白象(2-5 元)挤压
- **三个老头 IP 不可复制**:3 个退休老头是"天时地利人和"的产物,无法主动复制,后续翻红缺乏新主体反差

### 🔄 下次怎么做

- **保留"三个老头 + 沙市日化"怀旧叙事 + 加入"产品创新"**:怀旧是活力 28 的"良心底线",但要靠新 SKU(高端洗衣液/洗衣凝珠/洗洁精)持续输出反差点
- **加强 Z 世代沟通**:与 B 站/小红书 KOL 合作"反差发现"内容(三个老头切片 + 怀旧 + 国货良心),让 Z 世代参与"老国货新故事"
- **品牌叙事重新定位**:把"被外资雪藏 26 年"叙事升级为"40 年沙市日化匠心 + 三个老头良心 + 现在回归",避免被"卖国"舆论反噬
- **多平台正品矩阵**:天猫旗舰店 + 抖音官方 + 京东自营 + 拼多多官方 + 微信小程序,五平台正品矩阵
- **承接 #15 蜂花(低价格带)+ #16 白象(低价格带)+ #17 活力 28(中价格带)的"老字号国货焕新价格带阶梯"**:覆盖 9.9 元 → 19.9 元 → 39.9 元 → 49.9 元 → 285 元 五个价格带
