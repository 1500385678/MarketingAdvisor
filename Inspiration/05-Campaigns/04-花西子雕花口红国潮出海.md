## 1. 品牌

| 字段 | 内容 |
|---|---|
| 品牌 | 花西子(Florasis,中国国潮彩妆第一品牌,2017 年杭州成立) |
| 主推单品 | 雕花口红(同心锁雕花系列、苗族印象限定、百鸟朝凤雕花) |
| 营销类型 | 国潮营销(China-Chic) + 文化输出 + 美妆出海 + 工艺 IP |
| 行业 | 美妆 / 彩妆 / 国潮 |
| 调性反差 | 东方雕花工艺 × 现代彩妆 × 99-199 元轻奢价位 × Z 世代文化认同 |

**为何选这个案例**:花西子用"雕花 + 中国色 + 苗族/故宫/洛丽塔 IP"把一支口红从"消费品"升级为"东方美学载体",2021 年 7 月通过李佳琦直播间进入日本亚马逊,单品 1 小时销售额突破 1000 万日元,被日本媒体称为"中国化妆品爆买的起点";在 Instagram/TikTok 上以 Florasis 英文名走向 200+ 国家,标志中国美妆从"代工出海"转向"文化出海"。**用工艺 IP 撬动中国美学认同 + 跨文化溢价,适合作为"国潮品类"标杆范本**。

## 2. 目标

| 维度 | 目标 | 量化指标 |
|---|---|---|
| 品牌势能 | 把花西子从"国货彩妆"升级为"东方美学代表" | 2022 年百度指数"国潮彩妆"品类搜索占比 ≥ 30% |
| 海外营收 | 拉动中国美妆从"代工出海"升级为"文化出海" | 2022 年海外营收占比 ≥ 15%(亚马逊日本/美国 + Shopee 东南亚) |
| 文化穿透 | 用雕花工艺让中国文化符号被海外 Z 世代主动搜索 | Instagram #florasis 话题 ≥ 5w 篇笔记 + TikTok #florasischallenge ≥ 1w 视频 |
| 单品爆款 | 用雕花口红 1 个 SKU 撬动全品类关注 | 雕花口红系列年销售 ≥ 200w 支(2021 双 11 销 70w 支) |
| 心智 | 让"Florasis"在海外等同于"东方美妆" | 海外媒体正面报道 ≥ 50 篇(NY Times / 人民日报 / NHK 均有报道) |

**战略意图**:花西子要"用一支雕花口红,让中国审美被全球买单";**核心打法 = 东方工艺 IP 化 × 中国色号标准化 × 海外 KOL 文化种草 × 跨境电商闭环**。

## 3. 策略(5 段式)

| 段 | 输出 |

## 4. 创意(可执行层)

### 4.1 Slogan 层级
- **主 Slogan**:东方美学,雕花入妆(中文)/ Florasis: Where East Meets Beauty(英文)
- **辅 Slogan**:每一支雕花口红,都是一段东方故事;中国色,世界美

### 4.2 KV 视觉
- **主视觉**:同心锁雕花口红微距特写,口红膏体雕花 + 中国色胭脂红,周围配以水墨笔触 / 故宫红墙 / 苗银饰物
- **辅视觉**:与故宫文创联名(红墙黄瓦系列)、苗族印象限定(银饰 + 刺绣)、洛丽塔雕花(宫廷风)、百鸟朝凤雕花(国画风)
- **海外门店视觉**:东京/纽约/雅加达快闪店采用"东方庭院 + 中国色 + 雕花装置"主题,巨型雕花口红装置 + 中国色色卡墙 + 苗银工艺展示

### 4.3 落地页 3 屏(海外品牌官网 H5)
1. **首屏**:Florasis 品牌故事视频 30s + "Where East Meets Beauty"主视觉 + 雕花口红英雄大图
2. **二屏**:中国色号图鉴(12 色胭脂红/黛螺/鸦青/藕荷等) + 雕花工艺 360° 展示 + 故宫/苗族联名款入口
3. **三屏**:海外购买渠道(亚马逊/Shopee/官网) + KOL 真实测评视频 + 跨境直邮物流时效

### 4.4 媒介标题 30 变体(选 5)
- "花西子雕花口红,让日本女生排队 3 小时买中国货"
- "我用 6 国语言拆解 Florasis,发现它最中国的那支最火"
- "李佳琦直播间 1 小时破 1000 万日元,花西子凭啥让日本人买单"

## 6. 复盘(做得对/做错/下次怎么做)

### ✅ 做对
- **东方工艺 IP 化战略**:在国产彩妆普遍拼"性价比"时,把资源高度集中在"雕花 + 中国色 + 故宫/苗族 IP",形成"工艺 = 品牌 = 溢价"的护城河
- **中国色号标准化**:首创 12 色中国色卡(胭脂红/黛螺/鸦青/藕荷等),把"中国色"从模糊概念变成可购买 SKU,让"文化认同"转化为"消费意愿"
- **海外 KOL 文化种草**:不在海外硬投广告,而是找美籍华裔/日本美妆博主讲"东方美学故事",让文化认同驱动消费,避免"中国品牌 = 廉价"的刻板印象
- **跨境电商闭环**:日本亚马逊 + 美国亚马逊 + Shopee 东南亚同步铺货,海外用户从"看 KOL"到"下单"无缝衔接
- **溯源直播营销**:故宫/苗寨实地直播"雕花工艺 + 民族美学",把"中国制造"升级为"中国故事",反哺国内口碑

### ❌ 做错
- **产能跟不上爆款**:2021 双 11 雕花口红爆单后,工厂排产延迟 2-3 周,部分用户买不到现货转投竞品
- **海外版权纠纷**:部分雕花图案被指借鉴日本 / 韩国传统纹样,引发文化挪用争议
- **价格定位摇摆**:海外定价 30-50 美元 vs 国内 99-199 元,汇率波动 + 关税导致部分用户觉得"贵了/坑了"
- **文化解读偏差**:部分海外 KOL 解读"雕花 = 中国封建/束胸"等刻板印象,引发小范围舆情

### 🔄 下次怎么做
- **柔性产能 + 预售制**:对爆款雕花口红采用"预售 + 限量"双轨,从机制上缓解产能压力
- **海外文化前置审核**:核心雕花图案在 30+ 国家做"原创性 + 文化敏感性"双审核,建立海外品牌部
- **统一定价 + 跨境补贴**:海外市场统一定价 35-45 美元(对标 MAC / NARS),用国内利润反哺海外营销
- **海外 KOL 培训手册**:提供"中国色 + 东方美学"标准解读话术,避免 KOL 自发解读偏差
