# LLM 5 类创意/文案任务基线质量评估框架 v0.1

> Phase 0 · 待办 #15 起步草案 · 2026-09-15 建
> 维护:21-营销-Marketing 顾问 · 张勇 review
> 对应 `项目开发计划.md` 第 90 行:[ ] 评估 LLM 在 5 类任务(Slogan/KV 文案/落地页/媒介标题/复盘报告)的基线质量

---

## 1. 为什么需要这份评估

**问题**:MarketingAdvisor 的核心价值是"创意可执行"与"复盘可归因",这两块高度依赖 LLM 输出质量。但 LLM 输出不稳定:
- 同一个 prompt 跑 3 次会得到 3 个版本的 Slogan,质量参差不齐
- 中文文案常出现"AI 味"——空洞、套路、缺乏品牌人格
- 长文本(落地页/复盘报告)容易"流水账"或"开头很强 / 中段塌腰 / 结尾套话"

**目标**:在 Phase 1 MVP 上线前,**用 1 套可复用的评估方法,确定 5 类任务的"基线质量水位"**,回答 3 个问题:
1. 当前 LLM(Claude Sonnet 4 / Qwen-Marketing 微调)在 5 类任务上的"通过率 / 优秀率"是多少?
2. 哪些任务必须 LLM 介入、哪些可以用模板规则替代?
3. 哪类 prompt 调整 / Few-shot 加样本 / 后处理规则能最快拉升质量?

## 2. 5 类任务定义

| # | 任务 | 输入 | 输出 | 评估粒度 |
|---|---|---|---|---|
| T1 | **Slogan 生成** | 品牌 + 品类 + 调性 + 3 个关键词 | 1 句 ≤12 字 Slogan + 3 候选变体 | 单条 Slogan 维度评分 |
| T2 | **KV 文案(主视觉)** | 品牌 + 卖点 + KV 用途(海报/朋友圈/电梯) | 主标题(≤8 字) + 副标题(≤20 字) + 3 句文案 | KV 三件套整体评分 |
| T3 | **落地页文案** | 品牌 + 卖点 + 落地页用途(电商/注册/留资) | 3 屏文案:首屏 hook + 中屏利益点 + 末屏 CTA | 3 屏连贯性 + 转化力 |
| T4 | **媒介标题** | 品牌 + 卖点 + 渠道(小红书/抖音/微信/信息流) | 5 条标题 + 渠道适配标签 | 单标题维度评分 + 渠道适配 |
| T5 | **复盘报告** | 投放数据(Excel/CSV) + 品牌 + 周期 | "做对/做错/下次怎么做"三段式报告 + 关键 ROI 结论 | 报告整体 + 数据准确性 |

## 3. 评分维度(6 维,每维 0-5 分)

每条 LLM 输出从 6 个维度打分,总分 30 分;**24 分以上 = 优秀(可直接用)** / **18-23 = 合格(轻度修改)** / **18 分以下 = 不合格(重新生成或换 prompt)**。

| 维度 | 含义 | T1 Slogan | T2 KV | T3 落地页 | T4 标题 | T5 复盘 |
|---|---|---|---|---|---|---|
| **准确性** | 信息/数据是否正确,有无编造 | 卖点是否歪曲 | 是否冒用竞品词 | 是否编造卖点 | 是否编造功能 | 数据引用是否对得上 |
| **品牌契合** | 是否符合品牌人格与调性 | 调性匹配 | KV 风格匹配 | 落地页语调匹配 | 渠道人格匹配 | 报告口吻匹配 |
| **受众共鸣** | 是否打中目标人群痛点/痒点 | 痛点戳中度 | 利益点清晰 | 转化逻辑清晰 | 钩子强度 | 洞察深度 |
| **创意性** | 是否跳出套路,有无记忆点 | 记忆锚点 | 视觉想象空间 | 故事性 | 标题钩子 | 反共识洞察 |
| **可执行性** | 是否能直接落地使用 | 字数合规 | 三件套完整 | 屏间逻辑通 | 渠道合规 | 报告结构完整 |
| **去 AI 味** | 是否有"AI 套路词" | 套话密度 | 套话密度 | 流水账程度 | 标题党化 | 模板化程度 |

**AI 味典型黑名单词**(出现 1 次扣 0.5 分,出现 3 次以上该项直接判 0):
- "赋能 / 闭环 / 抓手 / 链路 / 沉淀 / 复盘 / 跑通 / 打通 / 战略 / 升级 / 重塑 / 创新 / 突破 / 引领 / 标杆 / 范式 / 赛道 / 心智 / 矩阵 / 全链路"

## 4. 评估流程(3 步,每次约 90 分钟)

### Step 1:样本集准备(20 分钟)
- 从 `Inspiration/05-Campaigns/` 17 个范本中,**每类任务随机抽 5 个真实场景作为测试题**(共 25 题)
- 每个场景准备:输入 prompt 模板 + 期望输出关键词 + 真实历史参考

### Step 2:LLM 批量跑(20 分钟)
- 每个场景分别用 Claude Sonnet 4 + Qwen-Marketing(若有)各跑 3 次
- 收集 5 × 5 × 3 × 2 = **150 条样本**

### Step 3:人评 + 自动化打分(50 分钟)
- 邀请 3 个评审(张勇本人 + 1 个营销朋友 + 1 个文案朋友)独立打分
- 取均值,差异 >3 分的项需评审再讨论
- 输出:**5 类任务的平均分 + 通过率 + 优秀率 + 高频失分点**

## 5. 基线水位判定标准(决策表)

| 平均分 | 判定 | Phase 1 决策 |
|---|---|---|
| ≥ 24 分 | 优秀 | **直接进 MVP**(无需改 prompt) |
| 20-23 分 | 合格 | 进 MVP + 在输出后挂"建议人工微调"提示 |
| 15-19 分 | 勉强 | **不直接进 MVP**,需 prompt 调优 + Few-shot 加样本 |
| < 15 分 | 不合格 | **该任务改走模板规则**(LLM 仅做填空) |

## 6. v0.1 已知问题 & 下一步

**v0.1 范围限制**:
- 暂未设计"渠道适配权重"(小红书要口语 / 信息流要钩子 / 微信要温和,各维度权重应不同)
- "去 AI 味"维度靠黑名单词机械判断,未引入语义检测(需要后续接 LLM-as-a-judge)
- 评估人仅 3 人,样本量不足以做统计显著性

**下一步(v0.2 候选)**:
- [ ] 引入 LLM-as-a-judge 做二评,把平均分与人评相关系数算出来
- [ ] 给 5 类任务设计**专属 prompt 模板 v1**,把评估高分样本作为 Few-shot
- [ ] 把"渠道适配"权重细化:T4 媒介标题拆 4 子任务(小红书/抖音/微信/信息流)分别评估
- [ ] 评估结果沉淀到 `data.db` 的 `llm_eval` 表,与版本号关联
